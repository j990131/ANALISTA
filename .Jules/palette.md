## 2026-07-04 - Custom Accessible Carousel State
**Learning:** When building custom tabbed/carousel interfaces spanning multiple files (React & Vanilla HTML), managing dynamic `aria-selected` and static roles (`role="tablist"` and `role="tab"`) is critical to screen reader accessibility. React easily handles dynamic attributes inline, but Vanilla HTML requires syncing the state update logic (e.g. `setAttribute("aria-selected", true/false)`) explicitly within the JS render cycle to maintain parity. Additionally, Spanish localized ARIA labels (e.g., 'Producto anterior') ensure an inclusive experience.
**Action:** When implementing standalone and React variants of UI components, enforce an explicit ARIA check pass: ensure stateful attributes like `aria-selected` or `aria-expanded` are properly mutated by Vanilla JS logic matching the declarative React version.
