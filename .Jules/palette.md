## 2025-01-20 - [ARIA translation and Carousel dynamic state sync]
**Learning:** In projects localized to Spanish, like the DentalPromo component, it is essential to ensure that ARIA labels reflect the language (e.g., 'Producto anterior' and 'Producto siguiente'). Moreover, in dual implementations (vanilla HTML and React components), dynamic `aria-selected` attributes and tablist/tab roles for carousel dot indicators must be manually set in the vanilla JS (`setAttribute`) to achieve full accessibility parity with the declarative React equivalent.
**Action:** Always provide translated, localized ARIA labels for icon-only buttons (prev/next) in non-English interfaces, and ensure JS toggle logic synchronously updates ARIA states alongside visual states to avoid screen reader desync.
