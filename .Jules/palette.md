## 2024-05-18 - Accessibility Attributes for Carousels
**Learning:** Carousels that function as product selectors require careful accessibility consideration. Using `role="tablist"` for the dot container and `role="tab"`/`aria-selected` for individual dots provides better screen reader context. Additionally, dynamic product info updates should use `aria-live="polite"` so screen readers announce the changes when the user navigates between items. Importantly, since the UI is in Spanish, all hardcoded ARIA labels must be explicitly translated to Spanish (e.g. "Producto anterior", "Ver producto N") to match the user context.
**Action:** Always include localized ARIA labels on icon-only nav buttons and apply `tablist`/`tab` patterns for custom carousel dot navigators. Ensure dynamic text areas announce changes via `aria-live`.
