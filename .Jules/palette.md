## 2024-05-24 - Dynamic Carousel Accessibility
**Learning:** For interactive, custom carousels relying on React states or dynamic DOM updates, simple button roles or basic ARIA labels are insufficient. Using elements like dots as navigation demands explicit state mapping via `role="tab"`, `aria-selected` to reflect active status, and `aria-live="polite"` on the text output to ensure screen reader users receive context updates natively without losing their orientation on the page.
**Action:** When implementing or fixing custom UI controls such as carousels or custom paginations, always verify screen reader context via `aria-live` for content containers and `aria-selected`/`aria-expanded` alongside their appropriate `role` attributes to guarantee semantic parity with visual cues.
