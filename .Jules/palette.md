## 2024-07-01 - Dental Promo Carousel Accessibility
**Learning:** In highly custom carousels (especially diagonal/3D layouts like DentalPromo), visual indicators like dots and icon-only navigation buttons often lack semantic meaning. Dynamic product information updates are completely missed by screen readers if not announced via aria-live. Syncing React declarative state (`aria-selected`) requires manual DOM attribute management in vanilla JS implementations.
**Action:** Always wrap custom dot indicators in `role="tablist"` and give individual dots `role="tab"` with `aria-selected` synced to active state. Icon-only navigation buttons must have `aria-label`. Ensure dynamic text containers have `aria-live="polite"`. Maintain a11y parity between React and vanilla implementations.
