## 2024-05-24 - Spanish ARIA Labels & Dynamic Tab Accessibility
**Learning:** For components with Spanish UI elements (like `DentalPromo`), standard icon-only buttons need explicitly translated `aria-label` attributes (e.g., 'Producto anterior', 'Producto siguiente'). Moreover, interactive carousels with dynamic mapping require setting standard accessibility features: `role="tablist"` on the container, `role="tab"` and `aria-selected` dynamically mapped on dot buttons, and explicit string interpolation for screen readers (`aria-label={'Ver producto ${i + 1}'}`). Dynamically changing product info content should have `aria-live="polite"` to alert screen readers of new selections properly.
**Action:** Always provide explicitly translated ARIA labels for non-English UI elements, implement `role="tab"` with `aria-selected` for dynamically generated pagination dots, and use `aria-live="polite"` on dynamically updated content sections.
