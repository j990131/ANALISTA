## 2024-07-02 - ARIA Additions for DentalPromo Carousel
**Learning:** Carousels and product galleries mapping dynamically over items in a language other than English must implement explicit translations for their ARIA labels (e.g., `aria-label="Producto anterior"` rather than implicit English assumptions). Furthermore, dynamic updates to text containers need `aria-live="polite"`, and navigation dots must use `role="tablist"`/`role="tab"` with synced `aria-selected` attributes to ensure screen readers correctly interpret the interactive state changes.
**Action:** When creating or maintaining dynamic carousels, always verify that ARIA labels are translated to the UI's language, use `aria-live` for dynamic content updates, and implement `role="tab"` semantics for pagination dots with correctly synced state.
