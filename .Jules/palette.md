## 2026-07-08 - [Dental Promo] Keyboard Navigation & Dynamic Screen Reader Feedback
**Learning:** When building custom carousel or tab-like components in both React and vanilla HTML, static visually-hidden text isn't enough. Screen readers need dynamic updates (`aria-live="polite"` on the text container, `aria-selected` toggling on `role="tab"` buttons). Furthermore, vanilla implementations lack React's declarative state for interactive elements (like the `onKeyDown` handlers), requiring explicit manual mapping of Enter/Space events to the interaction handlers to maintain accessibility parity.
**Action:** Always verify that interactive components (like product cards acting as triggers) have `tabIndex={0}`, a corresponding `role="button"` or `role="tab"`, and explicit keyboard event handlers (`e.key === 'Enter' || e.key === ' '`) in both the React components and their vanilla HTML counterparts to ensure equal access.
