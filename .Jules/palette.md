## 2026-07-20 - Accessible Dental Promo Carousels
**Learning:** Dynamic UI elements in this project (like carousels) require explicitly translated ARIA labels (e.g., 'Producto anterior') and dynamic attributes (`role='tablist'`, `role='tab'`, `aria-selected`, `aria-live='polite'`) to ensure screen reader accessibility.
**Action:** Always implement comprehensive ARIA attributes and focus management for interactive components, syncing state manually in vanilla HTML implementations.
