## 2024-06-17 - Add ARIA Labels and aria-live to Custom Carousel Component
**Learning:** For custom Spanish-language React UI components containing dynamically updating text elements and complex interactive indicators (like the custom diagonal carousel dot nav), assigning correct semantics (`role="tablist"` / `role="tab"`), `aria-selected` toggles, translated labels ("Producto anterior", "Producto siguiente", "Ver producto N"), and most critically `aria-live="polite"` on the active item description container significantly improves screen reader comprehension without visual regressions.
**Action:** Ensure that standalone HTML representation variants (`preview.html` / `dental-promo.html`) sync identically with component logic, applying JS DOM updates for `aria-selected` dynamically alongside `role` assignments. Maintain the `aria-live="polite"` on descriptions so item toggles announce effectively across standalone environments.
