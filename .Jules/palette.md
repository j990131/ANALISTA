## 2024-05-18 - [Accessibility in localized dynamic carousels]
**Learning:** When adding ARIA properties to localized components (e.g., Spanish DentalPromo), it is crucial to ensure that aria-labels such as `aria-label="Producto anterior"` and interpolated values like `aria-label={\`Ver producto ${index + 1}\`}` are properly translated. Furthermore, dynamic text updates like price and description require `aria-live="polite"` on their container so that screen readers announce these updates smoothly without interrupting the user's flow.
**Action:** When implementing UI component translations or localizations, ensure that accessibility features like ARIA labels are also accurately translated, and wrap any dynamically changed informational text containers with `aria-live="polite"` to maintain screen reader context.
