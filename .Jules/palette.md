## 2024-11-20 - Accessible Dynamic Carousels
**Learning:** Carousels that conditionally render state in a dynamic loop (e.g. mapping elements via React or vanilla JS DOM manipulation) require strict syncing of \`role='tablist'\`, \`role='tab'\`, and \`aria-selected\` alongside standard localized interactive aria-labels (like "Producto anterior", "Ver producto N") to allow screen reader users to properly interpret the UI parity between React applications and vanilla html fallback templates.
**Action:** When auditing or implementing dynamic visual indicators (like dots for carousels), always bind \`aria-selected\` dynamically to the active state index, assign role='tab'/'tablist', and inject \`aria-live="polite"\` onto the content container that displays dynamically active text to improve screen reader announcement of dynamic transitions.
