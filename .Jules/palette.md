## 2024-06-22 - Spanish accessibility and dynamic UI element considerations for carousels
**Learning:** For internationalised or non-English applications, default accessibility labels (like generic 'Next' or 'Previous') are insufficient. In this Spanish UI, using `aria-label="Producto anterior"` and `aria-label="Producto siguiente"` is necessary for icon-only navigation buttons. Additionally, dynamic carousels using dots need precise role management (`role="tablist"` on the container, `role="tab"` with `aria-selected` and `aria-label="Ver producto ${i + 1}"` on the dots) and dynamic content containers need `aria-live="polite"` so screen readers correctly interpret state changes without losing context.
**Action:** Always verify the language of the UI and provide correctly translated `aria-label` attributes. When implementing custom UI controls like dot paginations or dynamic carousels, always explicitly map the custom control semantics back to native ARIA roles (`tablist`, `tab`, `aria-selected`, `aria-live`) to ensure robust screen reader support.
