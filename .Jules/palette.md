## 2024-06-25 - Accessible Dynamic Carousels
**Learning:** Carousels that update dynamically but don't cause page reloads need specific ARIA roles to be accessible. Icon-only navigation buttons must have `aria-label`s. The active item's text container must use `aria-live="polite"` so screen readers announce changes. The dot indicator container must be defined as a `tablist` with `role="tablist"` and a descriptive `aria-label`, and the individual dots need `role="tab"`, a descriptive `aria-label` (e.g., "View product 1"), and a dynamic `aria-selected` attribute indicating state.
**Action:** Always verify custom interactive UI elements like carousels have matching `aria-live` containers for dynamic text, explicitly labeled control buttons, and properly structured `tablist`/`tab` attributes with state tracking for pagination indicators.
