## 2024-05-15 - DentalPromo Carousel Accessibility
**Learning:** Dynamic, custom carousels (especially non-standard ones like diagonal carousels) require manually setting `role="tablist"` on the pagination dots container, `role="tab"` on the dots themselves, and dynamically updating `aria-selected` to reflect state. Furthermore, ARIA labels for navigation buttons and product index should be localized (e.g. Spanish) if the UI language is Spanish. Product info updates must be announced via `aria-live="polite"`. In vanilla JS implementations, state like `aria-selected` must be manually kept in sync with visual states (`d.classList.toggle`).
**Action:** When creating custom carousels, apply localized `aria-label`s to navigation controls, make the dots a tablist with updated `aria-selected` states, and mark the dynamic content container as an `aria-live` region. Ensure vanilla JS implementations explicitly sync ARIA attributes during render cycles.
