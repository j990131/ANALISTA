## 2024-05-24 - Accessibility for Custom Carousels
**Learning:** Custom carousel components built with standard divs lacking semantic meaning need specific ARIA roles to be usable by screen readers. A common pattern is applying `role="region"` and `aria-roledescription="carousel"` to the container, and `role="group"` with `aria-roledescription="slide"` and an explicit label to individual items, especially when they are non-focusable `<div>` elements meant to act as product cards. Icon-only navigation buttons (`‹`, `›`) also critically need `aria-label` attributes to define their purpose.
**Action:** When implementing or modifying custom carousels that use non-semantic elements for layout, always explicitly verify and add the `region`/`carousel` roles for the container and `group`/`slide` roles for items, along with providing descriptive labels for all icon-only navigation controls.
